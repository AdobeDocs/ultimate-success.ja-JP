# CJAでのAdobe Data Insights Agentの運用

Adobe Data Insights AgentをCustomer Journey Analytics内の実用的な日々のワークフローに変換する方法について説明します。 このセッションでは、チームが自然言語プロンプトを使用して、分析を加速し、セルフサービスのインサイトを可能にし、手作業によるレポートへの依存を軽減する方法を紹介します。 Adobe insightへの移行時間を短縮し、データにもとづく意思決定を組織全体で拡張するために、ぜひご活用ください。
