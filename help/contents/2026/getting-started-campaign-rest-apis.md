# 統合を迅速に開始：キャンペーン REST APIの基本を学ぶ

Campaign REST APIは、エンゲージメントの瞬間をマーケティングまたはサービスのアクションと橋渡しすることで、価値ある顧客インタラクションを作成する合理的な方法を提供します。 このセッションは、Ultimate Success シリーズの一部であり、これらのAPIを効果的に理解し、使用するために設計されています。

## 重要な留意点

- ユースケースを小さくテスト可能な統合ストーリーに変換する方法を学びましょう。
- APIが価値を生み出す場所と、それが適切なツールではない場所を把握します。
- リクエストシェイプの作成、ガードレールの設定、制作へのパスの確立に関するインサイトを得ることができます。

## 概要

Adobe Campaign REST APIは、単なるツールではなく、顧客とのインタラクションを即座にパーソナライズするためのゲートウェイとなります。 これらのAPIを使用すると、次のことが可能になります。

- 確認メールの送信やユーザー設定の更新など、顧客のアクションにもとづいて特定のアクションをトリガーできます。
- Adobeや外部システムなどの他のアプリケーションとのシームレスな統合を実現します。
- カート放棄の通知、ウェルカムメール、トランザクションの確認など、低遅延のイベント主導のユースケースをサポートします。

## 議題

1. **ビジネスの概要：**
   - REST APIの戦略的コンセプト。
   - API活用のための顧客モーメントの特定。
2. **技術的なインサイト：**
   - API エンドポイントの設定と認証。
   - IMS認証および開発者コンソールプロジェクトの設定。
   - エンドポイントの選択とペイロードのカスタマイズについて。
3. **デモ：**
   - Adobe Campaignでのイベントタイプとテンプレートの設定。
   - Postmanを使用したSOAPとREST APIの呼び出し。
   - API呼び出しとその結果の実用的な例。
