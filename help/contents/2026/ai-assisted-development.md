# AEM Agent Skills:AIを活用した開発の適切な実施

AdobeのオープンソースのAEM Agent Skillsが、Adobeで検証されたコンテキストを使用してコーディングアシスタントを支援し、一貫性のある本番用のAEMコードを作成する方法をご覧ください。

>[!VIDEO](https://video.tv.adobe.com/v/3502967/?learn=on&enablevpops)

## 学習すること

- AI コーディングアシスタントに適切なAEM コンテキストを提供することの重要性を理解します。
- Agentが、Cursor、Copilot、Claude Codeなどのツールの基礎をどのようにスキルしているかをご覧ください。
- 最初のプロンプトから、コーディングの一貫性と本番環境への対応を改善するための手法を学びます。

## ターゲットオーディエンス

このセッションは、次のような場合に最適です。

- AEMプロジェクトを合理化したい開発者。
- 制作ワークフローの強化を目指すプロジェクトリーダー。
- 初心者、中級、上級レベルの利用者が、AIを活用した開発手法を導入しようとしている場合。

## 議題

1. **はじめに**
   - AEM Agent Skillsの概要。
   - 開発におけるコンテキスト AIの必要性。

1. **エージェントのスキルを探しています**
   - エージェントスキルの定義と理解。
   - AI ドリフトを低減するためのエージェントスキルの役割。
   - オープンソースの貢献とコミュニティの関与。

1. **AEM Agent Skillsの主な機能**
   - コンポーネントスキルの作成：コンポーネント作成を簡略化します。
   - Dispatcher スキル：パフォーマンスとセキュリティを高める設定の強化
   - コード評価スキル：AEMのベストプラクティスとの整合性を維持する

1. **ライブデモ**
   - AEM Agent Skillsの使用例。
   - コンポーネントの作成、Dispatcherの管理、コード品質の評価に関するインタラクティブなチュートリアルです。

1. **Q&amp;A セッション**
   - オーディエンスの質問に対応し、追加リソースを提供する。

## リソースと次のステップ
